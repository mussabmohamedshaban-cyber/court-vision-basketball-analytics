# CourtVision Analytics: High School Basketball Performance Tracker (Libya)

## Overview & Motivation
Developed on a school workstation migrated from Windows to **Linux Mint**, **CourtVision Analytics** is a lightweight Python tool designed to help our high school basketball team optimize lineups, shot selection, and fourth-quarter stamina. Combined with active on-court playmaking and team morale mentorship, this tool helped guide our squad to a **3rd-Place Tournament Finish**.

## Technical Foundations
* **Google Data Analytics Principles:** Structured CSV data ingestion, cleaning, and calculation of advanced basketball metrics including **Effective Field Goal Percentage (eFG%)** and **Assist-to-Turnover Ratio (AST/TO)**.
* **Harvard CS50x (Weeks 3 & 4) Algorithmic Logic:** Implements custom in-memory dictionary structures and a **Selection Sort algorithm** (`selection_sort_players`) to rank player impact scores without external library bloat.

## Repository Files
1. `court_vision_analytics.py` — Main Python analytics engine and custom sorting algorithm.
2. `team_match_stats.csv` — Tournament dataset tracking shooting splits, playmaking, and 4th-quarter clutch scoring.
